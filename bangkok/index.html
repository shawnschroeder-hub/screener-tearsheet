Does an incognito window or a VPN get a lower price?

Not on Google Flights. The same three trips were priced with the site's location set to six countries, from inside an incognito browser with no cookies or sign-in, and every country returned the same fare. The pennies of difference are only today's exchange rate.

Why: Google Flights pulls the fare the airline files for the country you are "shopping from", and these airlines file the same fare for all six. A VPN only changes which country you appear to be in, which is exactly the setting changed here, so a VPN would not have found anything different. Incognito mode never affects airfare; prices are not raised for repeat searches.

Where location can still matter: an airline's own website in a local currency (for example booking Cathay or EVA on their Thai site). That is a different check from Google Flights and was not part of this run.
